# Student Marks and Average Calculator

## 1. Problem Statement
Write a Python program that accepts a student's name and marks in three subjects, then calculates and displays the total and average marks.

## 2. Objectives
- Practise variables and basic data types.
- Use input and output operations.
- Convert entered marks to numeric values.
- Apply arithmetic operators.

## 3. Assumptions
- The student enters marks as numbers.
- Marks are entered on the same scale for all three subjects.
- This introductory version does not validate the mark range.

## 4. Concepts Used
`input()`, `print()`, variables, `float()` type conversion, addition, and division.

## 5. How to Run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this folder.
3. Run: `python main.py`

## 6. Expected Result
The program displays the student's name, total marks, and average marks.

## 7. Conclusion
This program demonstrates how Python variables, input/output, type conversion, and arithmetic operators can be used to process student marks.
