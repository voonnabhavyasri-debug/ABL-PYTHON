# Algorithm

1. Start.
2. Input the number of units produced.
3. Input material cost per unit and labour cost per unit.
4. Input total wastage cost and total machine cost.
5. Input selling price per unit and target profit.
6. Check whether units are positive and all other values are non-negative.
7. If the inputs are invalid, display an invalid-input message.
8. Otherwise, calculate total material cost and total labour cost.
9. Calculate total production cost by adding material, labour, wastage, and machine costs.
10. Calculate sales revenue by multiplying units by selling price per unit.
11. Calculate profit by subtracting total production cost from sales revenue.
12. Calculate cost per unit.
13. Display all calculated values.
14. If profit is greater than or equal to target profit, display “Profit Target Achieved”; otherwise display “Profit Target Not Achieved”.
15. Stop.
