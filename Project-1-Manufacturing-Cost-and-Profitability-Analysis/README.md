# Project 1: Manufacturing Cost and Profitability Analysis

**Python Activity-Based Learning (ABL) — Case Study 8**

## Project overview
This program calculates manufacturing expenses, total production cost, cost per unit, sales revenue, and profit. It checks whether the profit reaches a specified target.

## Files
- `problem_statement.md` — problem statement, objectives, assumptions
- `algorithm.md` — step-by-step algorithm
- `pseudocode.txt` — pseudocode
- `flowchart.svg` — flowchart diagram
- `main.py` — Python program
- `test_cases.md` — test data and expected results
- `output/expected_output.txt` — expected console output for Test Case 1
- `output/README.md` — instructions to capture the actual output screenshot

## How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this folder.
3. Run: `python main.py`
4. Enter the requested values. For Test Case 1, use the values listed in `test_cases.md`.

## Syllabus concepts used
Variables, numeric data types, input/output, arithmetic operators, conditional statements, and basic validation.

The output text is an expected-output reference. Run the program yourself and add a screenshot of the real execution to the `output/` folder before submitting.
