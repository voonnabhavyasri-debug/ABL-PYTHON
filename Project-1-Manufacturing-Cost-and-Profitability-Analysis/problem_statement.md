# Problem Statement

Manufacturing a product involves expenses such as materials, labour, wastage, and machine usage. A manufacturer needs to know the total production cost and whether sales will achieve a required profit target.

Develop a Python program that accepts the number of units produced, material cost per unit, labour cost per unit, total wastage cost, total machine cost, selling price per unit, and target profit. The program should calculate total production cost, cost per unit, total sales revenue, and profit. It should then display whether the profit target is achieved.

## Objectives
1. Calculate total material cost.
2. Calculate total labour cost.
3. Calculate total production cost.
4. Calculate cost per unit, sales revenue, and profit.
5. Compare profit with the target profit.

## Assumptions
1. Number of units must be greater than zero.
2. Material cost and labour cost are entered per unit.
3. Wastage cost and machine cost are total batch costs.
4. Selling price is entered per unit.
5. Target profit is a total batch amount.
6. All costs, prices, and target profit must be non-negative.
7. Inputs are entered in numeric form.
