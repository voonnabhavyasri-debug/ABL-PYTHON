# Problem Statement
Compare a student's short text answers with stored model answers, count exact matches, and calculate the score.

## Objectives
- Store model answers in a list.
- Accept and normalize student answers.
- Compare answers without case sensitivity.
- Calculate marks and percentage.

## Assumptions
There are three questions worth one mark each. Answers are compared exactly after trimming spaces and converting to lowercase. This is not intended to grade descriptive answers.
