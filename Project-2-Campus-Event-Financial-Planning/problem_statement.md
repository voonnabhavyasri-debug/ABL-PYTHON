# Problem Statement

A campus event requires money for the venue, equipment, catering, transport, and certificates. The organizers need to calculate the total event cost, the amount collected from participant registration, the amount covered by sponsorship, any remaining shortfall, and the minimum number of registrations required to cover the cost.

## Objectives
1. Calculate total event expenses.
2. Calculate registration income and sponsorship income.
3. Determine the remaining amount to be covered.
4. Calculate the minimum registrations needed to break even.

## Assumptions
- All amounts are non-negative.
- Registration fee is the amount paid by each participant.
- Sponsorship is a total amount.
- The minimum registration count is rounded up to a whole participant.
- This simplified model assumes costs remain fixed as registrations increase.
