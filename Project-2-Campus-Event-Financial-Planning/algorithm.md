# Algorithm
1. Start.
2. Input venue, equipment, catering, transport, and certificate costs.
3. Input registration fee, expected registrations, and sponsorship amount.
4. Validate that costs, fees, sponsorship, and registrations are non-negative.
5. Calculate total event cost.
6. Calculate registration income and total available income.
7. Calculate surplus or shortfall.
8. If registration fee is positive, calculate minimum registrations needed to cover costs after sponsorship; otherwise explain that break-even through registration is not possible.
9. Display the financial summary.
10. Stop.
