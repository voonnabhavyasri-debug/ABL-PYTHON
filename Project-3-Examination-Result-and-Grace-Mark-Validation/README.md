# Project 3: Examination Result and Grace-Mark Validation

**Python Activity-Based Learning (ABL) — Case Study 11**

## Project overview
Examination Result and Grace-Mark Validation is implemented using basic Python concepts from the assigned syllabus.

## Files
- `problem_statement.md` — problem statement, objectives, assumptions
- `algorithm.md` — algorithm
- `pseudocode.txt` — pseudocode
- `flowchart.svg` — flowchart diagram
- `main.py` — Python source code
- `test_cases.md` — test cases and expected results
- `output/expected_output.txt` — reference output
- `output/README.md` — instructions to capture an actual screenshot
- `conclusion.md` — conclusion

## How to run
Run `python main.py` in a terminal and enter the values from the test case you want to try.

## Submission reminder
The expected output is a reference, not a screenshot of an actual execution. Run the program and add your own screenshot to the `output/` folder before submitting.
