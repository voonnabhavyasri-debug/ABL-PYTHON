# Algorithm
1. Start.
2. Input marks for three subjects.
3. If any mark is outside 0 to 100, display invalid input.
4. Otherwise, set remaining grace marks to 5.
5. For each subject, if marks are below 35 and the difference is at most the remaining grace marks, add the required grace marks.
6. Reduce the remaining grace-mark balance.
7. Check whether every final subject mark is at least 35.
8. Display original marks, final marks, grace marks used, and result.
9. Stop.
