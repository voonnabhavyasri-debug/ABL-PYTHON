# Problem Statement
Calculate a student's current attendance percentage and the minimum consecutive future classes that must be attended to reach a required attendance threshold.

## Objectives
- Calculate current attendance percentage.
- Check whether the threshold is already met.
- Calculate future classes needed.
- Display the projected attendance.

## Assumptions
Total classes must be positive; attended classes must be from zero to total classes; required percentage must be greater than 0 and at most 100. All future classes are attended.
