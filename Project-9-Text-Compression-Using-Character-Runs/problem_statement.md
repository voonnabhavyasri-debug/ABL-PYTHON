# Problem Statement
Represent consecutive repeated characters as the character followed by the number of repetitions. For example, `aaabbc` becomes `a3b2c1`.

## Objectives
- Accept a text string.
- Find runs of repeated consecutive characters.
- Count each run.
- Display the compressed representation.

## Assumptions
The program preserves letter case and spaces. Every run is written as a character followed by its count. This educational method may not shorten every string.
